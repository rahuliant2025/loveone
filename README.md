# Rahul ❤️ Shristi — Chapter 2: Cinematic Butterfly Wedding Experience

A mobile-first interactive cinematic wedding story celebrating the union of **Rahul Patel & Shristi Singh** on **11 December 2026**.

## Visual Direction
- **Central Storyteller**: Glowing Blue Butterfly guiding the visitor through every chapter.
- **Palette**: Deep Royal Blue, Midnight Blue, Metallic Gold, Warm Amber/Orange, and Subtle Sacred Red.
- **Atmosphere**: Royal, Cinematic, Emotional, Spiritual, Modern Indian.
- **Target Experience**: 1080 × 1920 mobile viewport (WhatsApp first) and fully responsive across 360px–430px, tablet, and desktop.

## Project Structure
```
/assets
  /groom         (Dedicated groom character visual assets)
  /butterfly     (Butterfly models / vectors / luminescent sprites)
  /backgrounds   (Cinematic royal backgrounds & environments)
  /music         (Curated soundtrack assets)
  /icons         (Traditional and cultural ceremonial icons)
  /textures      (Zari, gold leaf, ambient grain textures)
  /fonts         (Typography assets)
/css
  design-system.css  (Color tokens, typography scale, responsive viewports)
  main.css           (Hero stage, butterfly character & cinematic layers)
/js
  butterfly-engine.js    (Butterfly state machine & particle emitter)
  cinematic-timeline.js  (GSAP core story orchestrator)
  main.js                (Main entry point)
index.html           (Fresh HTML5 cinematic canvas)
```

## Technologies
- **HTML5 & CSS3** (Mobile-first responsive architecture)
- **Vanilla Modern JavaScript**
- **GSAP 3.12+** & **GSAP ScrollTrigger** (for cinematic storytelling and scroll-controlled navigation)
- **Three.js** (Optional/Reserved if needed for 3D shaders)
